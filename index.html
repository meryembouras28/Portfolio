Pipeline multimodal de modération de contenu pour le texte, l’image et la vidéo, exposé par une API FastAPI. Modèles Transformers pour le texte, détection visuelle et OCR pour les images, orchestrés pour analyser les vidéos et noter chaque catégorie.

  • Python
  • FastAPI
  • NLP
  • Transformers
  • Vision
  • OCR
  • Whisper
02

Road Scene Copilot

Copilote de conduite : détection d’objets avec YOLO11, analyse du risque (zone, distance, niveau) et conseils en langage naturel par un LLM à backends interchangeables. API FastAPI, tests unitaires, code sur GitHub.

  • YOLO11
  • FastAPI
  • LLM
  • pytest
03

Prédiction du prix de voitures

Pipeline de régression pour prédire le prix de revente de voitures d’occasion : analyse exploratoire, prétraitement avec Scikit-learn, comparaison de quatre modèles (régression linéaire, arbre de décision, forêt aléatoire, Ridge) en validation croisée. R² de 0,75 sur le jeu de test.

  • Python
  • Pandas
  • Scikit-learn
  • Seaborn

PageRank et chaînes de Markov

Modèle mathématique de la navigation web : les pages sont des états et les liens des transitions. PageRank implémenté en Python à partir de la matrice de transition, avec analyse de la convergence.

  • Chaînes de Markov
  • Probabilités
  • Algèbre linéaire
  • PageRank
